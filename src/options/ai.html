默认 168 小时（7 天）。网页刷新后可恢复近期的 AI 翻译；再次打开同一 PDF 并翻译时也会复用缓存。更换模型、语言、专家、风格或术语后会重新匹配。无痕窗口不保存缓存。

结果只保存在本机，不包含 API Key 或原始 PDF 文件。可随时使用“重新翻译”跳过缓存。关闭缓存会删除已有结果。
