# 本地图片翻译

图片入口位于翻译工作台的「图片」标签页。支持 PNG、JPEG、WebP（20 MB、2500 万像素以内），包括 PDF 截图。可选择文件、点击「粘贴图片」或直接按 Ctrl+V 粘贴截图，无需先保存文件；仅在图片标签页处理图片粘贴，普通文字粘贴保持原有行为。剪贴板只在用户点击或粘贴时读取，不后台监视；权限被拒绝或浏览器不支持按钮读取时，可用 Ctrl+V。图片长边超过 2000 像素时缩小后识别。流程是选图或粘贴、选择 OCR 模型、点击识别、检查并修改文字、选择翻译服务并翻译。支持复制和下载双语 TXT，原图与识别框保留。

网页控制面板「划词翻译 → 圈选翻译 → 开始圈选」支持拖框截图；反向拖动也可，Esc 取消。视频可暂停后圈选字幕。浏览器截图在本机裁剪，以实际截图分辨率换算坐标；截图时隐藏选择层和悬浮按钮。裁剪图通过短期会话存储交给图片工作台，自动识别但不自动发起 AI 翻译，保留当前页面选择的模型、专家、术语库、风格与目标语言。请检查识别文字后再翻译。当前浏览器不支持会话存储或截图时会明确提示使用手动截图入口。

「模型与术语设置 → 查看缓存内容与选择删除」可管理自定义 AI 和免费翻译的持久缓存。AI 记录按服务、模型、来源标题和译文搜索；旧记录没有来源信息，仍可查看译文。免费磁盘缓存可选择服务 / 语言并按原文或译文搜索，默认关闭磁盘缓存时不列出临时内存结果。删除不会擦掉当前已显示在网页上的译文，后续翻译会重新查询；未删除记录仍可复用，删除期间的旧请求不会把结果写回磁盘。

模型可选 PP-OCRv5 mobile（检测＋识别 TAR 21.54 MB）与 PP-OCRv6 small（31.21 MB），均来自 Paddle 官方，大小不包括随包分发的运行时。第一次识别从官方资源地址下载，SHA-256 验证成功后写入本机 Cache Storage。模型切换不会混用权重；清除模型按钮删除这两套权重缓存，下次重新下载。浏览器可能因存储限制回收缓存。

OCR 在专用 Worker 中使用 CPU / WASM 单线程运行。取消会终止 Worker 和未完成的模型下载；翻译复用既有免费 / 自定义 AI 通道及其缓存。图片不离开本机，点击翻译才发送编辑后的文字给所选服务。图片识别模型与翻译模型独立；专家、风格、术语选项传入 AI 请求，免费服务不使用 AI 提示词。

OCR 不等于公式或图形结构识别。旋转的小字、上下标、数学符号和流程图的阅读顺序可能识别错误，因此先展示可编辑文字，由用户检查。第一版输出双语文字，不在原图中擦除或替换标签，不自动对整个 PDF 或网页视频进行识别。

Chrome MV3 不允许普通扩展页面执行动态 JavaScript。scripts/opencv-csp-loader.cjs 在打包时把锁定 OpenCV 4.10.0 的 createNamedFunction、makeDynCaller、craftInvokerFunction 和 __emval_get_method_caller 改为静态闭包，保留参数校验、类型转换、析构和返回值语义；发现未知动态代码时构建失败，不降低 CSP。间接的 new_(Function, …) 同样需要替换，否则运行时初始化会中断，留下缺少基础类型的 Mat 构造函数。webpack.ocr.cjs 把适配后的 OpenCV 单独打包，并排除 SDK 未使用的第二套 Worker。图片在 Worker 中经 OffscreenCanvas 转换为 cv.Mat，避开 SDK 默认转换器对 document 的依赖。原始代码和许可来自 npm 锁定依赖，可通过 npm ci 重现。

文字默认按 OCR 框的位置合并同行碎片，再把相邻、对齐、字号接近的正文行整理为段落。大间距标签、旋转文字和不同列保持独立，列表项目保持分段。也可选择「按原图分行」或「原始文字框」；切换会覆盖编辑框中的手动修改，不重新运行 OCR。这个启发式整理不能恢复所有复杂版式，公式和多列阅读顺序仍需检查。

翻译按最多 6 段、3000 字符分批，显示已完成段数和等待秒数；每批返回即显示段落双语结果，后续失败或取消保留已返回的结果，可复制或下载带 `.partial` 标记的 TXT。普通官方 DeepSeek Flash / V4 Pro 翻译显式使用非思考模式，避免默认思考增加等待；第三方兼容地址和显式选择的旧 `deepseek-reasoner` 不添加此参数，缓存区分有效请求模式。

## 验证

执行 `npm run test:image-layout` 验证碎片、段落、列表、列间距和旋转标签整理，完整构建后运行 `npm run test:image`。测试使用隔离 Chromium/Edge 的真实扩展 Worker 和浏览器 CSP，默认从官方地址获取四份权重（不上传图片）。如已有本地权重，可通过环境变量 `TWP_OCR_MODEL_DIR` 指定包含 PP-OCRv5_mobile_det.tar、PP-OCRv5_mobile_rec.tar、PP-OCRv6_small_det.tar、PP-OCRv6_small_rec.tar 的目录；测试将官方下载响应替换为这些字节，仍执行 SHA-256 校验。

测试图片由浏览器绘制为中英文字，不需要分享用户文档。翻译接口采用本地模拟服务，验证模型切换、下载和离线复用、识别后修改、翻译服务/专家/术语传递、缓存复用、取消、失败重试及双语导出。

可选环境变量 `TWP_OCR_SAMPLE_DIR` 指向包含 `flowchart.png` 的本地 PDF 截图样本目录，追加检查原教材流程图的八个主要标签。该样本只供本地验证，不进入安装包或源码包。
