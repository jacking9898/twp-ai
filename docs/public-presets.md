# 专家与术语：默认数据和本地导入

## 默认目录与数量

默认数据保存在仓库的 `src/lib/builtinPresets.js`，构建时直接打包；运行时不下载第三方配置。`src/lib/aiPresets.js` 负责基础专家、风格和目录整合。

- 参考目录中的 **41 个专家类别全部保留**，任务提示词由 页渡 · Yedu 重新编写，包含领域用词、上下文处理和内容保留要求。另有通用、机器学习 / 数据科学、软件开发 3 个本地基础专家，因此界面共 44 个专家、10 种风格。
- 默认共 **31 个术语库**：原快照的 36 个库移除 6 个电子游戏库后保留 30 个，其中「访问控制」扩展为「计算机科学」；另新增本项目的「LLM / AI」库。其余参考库的语言版本及词条数量保持不变。另有不计入 31 个库的「我的默认术语」入口。
- 共 **3,634 条语言版本配置**：简体中文 1,971 条、繁体中文 1,617 条、各目标语言保留原词 46 条。同一原词的不同语言版本分别计数，不等于 3,634 个独立概念。
- 歌声合成（Vocaloid）在参考快照中是空库，保留 0 条；界面明确显示暂无词条，不编造内容凑数。

机器可读核对表见 [preset-inventory.json](preset-inventory.json)，保留参考日期、快照哈希、专家 ID、移除项和原始逐库条数，并单独记录扩展库、新增库及当前总数。`npm run test:ai` 会验证条数、语言集合、重复词、专家覆盖及旧设置回退。

## 计算机科学与 LLM / AI

- **计算机科学**：每种中文版本 125 条。保留原访问控制的 8 条简体术语及内部 ID `public-access-control`，已有选择继续有效；补充操作系统、网络、数据结构与算法、编译、数据库、分布式计算和软件工程，并提供对应繁体版本。
- **LLM / AI**：每种中文版本 136 条，ID 为 `builtin-llm-ai`。覆盖模型结构、词元与提示词、训练微调、LoRA / RLHF / DPO、推理解码、RAG、向量检索、智能体、评估及安全用语。长名称和常用缩写各自作为可匹配词条，缩写译文保留原缩写。
- 新增条目由本项目整理，按 MPL-2.0 提供；计算机科学库原有 8 条的来源记录仍保留，不把原条目的许可改称本项目许可。其他术语库及专家没有因本次扩展缩减。

常用术语核对参考：[Google 机器学习术语表](https://developers.google.com/machine-learning/glossary?hl=zh-cn)、[Hugging Face LLM 生成指南](https://huggingface.co/docs/transformers/main/zh/llm_tutorial)、[Microsoft 云设计模式](https://learn.microsoft.com/zh-cn/azure/architecture/patterns/)。这些链接用于术语核对，不表示整份词库复制自其中某一文档。

## 移除的术语库

移除通用游戏、剑星服装、Shelter69 社区、绝地潜兵 2、博德之门 3、鸣潮，ID 分别为 `public-game`、`public-stellar-blade-clothing`、`public-Shelter69-Slang`、`public-hd2`、`public-bg3`、`public-wuthering-waves`。旧设置中选中的这些内置库在使用时回退到通用库。

此处的「游戏」按电子游戏处理，国际象棋、体育、高尔夫、网球和算法竞赛保留。游戏、Steam、电竞等专家类别保留，个人创建的专家和术语库不删除、不覆盖。

## 术语如何使用

保留标准术语的正确译法，按原有词条整理并校订少数明显用词问题，不通过乱换同义词来制造「改写」。例如补全人名「马克·扎克伯格」，澄清同人标签中的存档警告、原作设定及算法竞赛的首次解题表述。并未声称所有专业条目已经逐项审校。

术语按目标语言应用，`auto` 词条保留原词。只向 AI 发送当前文本命中的词条，最多 200 条 / 16000 字符，长词优先；个人默认术语覆盖同名词条。谷歌、微软、Yandex 接口不支持本项目的 AI 提示词参数。设置页可以切换简繁体版本、查看条数、查看来源和另存为个人库。

## 来源记录

参考的是 2026-10-03 已保存的 [immersive-translate/prompts](https://github.com/immersive-translate/prompts) 专家目录和 [immersive-translate/terms](https://github.com/immersive-translate/terms) 术语快照，不代表这些上游仓库今后的最新内容。

专家保留类别与 ID，提示词使用本项目重新编写的版本，按 MPL-2.0 提供；没有把第三方提示词原文换个署名。参考术语库保留大量固定译法及上游分类，逐库记录原作者和来源链接；它们与本项目新增条目的来源分别记录，不能将整个默认集合称为完全独立编写的数据。改写提示词或校订术语不等于取得第三方集合的再分发授权；参考快照未找到明确的根目录再分发许可，第三方术语数据不重新声明为 MPL-2.0。公开发布时的许可问题仍需确认，见 [第三方说明](../THIRD_PARTY_NOTICES.md)。

完整原始备份仍在 Git 忽略的 `.local-data/` 中；其中的原始专家提示词和被移除的游戏词库不随安装包或源码包分发。正常构建只读取已纳入源码的默认数据，不需要该本地目录。

## 本地转换与自定义

转换工具保留为可选开发工具，正常构建不运行它。输入是你已经取得、并有权使用的 YAML / CSV 数据，工具不会联网抓取，也不会执行其中的脚本。

```sh
python -m pip install PyYAML
python scripts/import-public-presets.py <包含 prompts-main 和 terms-main 的目录>
```

输出仅写入 `.local-data/presets.json`、`*.prompt.txt` 和按语言区分的 `*.terms.txt`。它不会修改 `src/`，不会将转换结果加入默认包。

在扩展「模型与术语设置」中新建专家，粘贴对应 `prompt.txt` 内容；新建术语库，选择与文件一致的目标语言，粘贴 `terms.txt`。专家限制为 6000 字符，单库最多 10000 条，超过界面限制时需要自行编辑或拆分。JSON 用于本地审阅与工具处理，当前 UI 不提供整包 JSON 导入。

