# TWP 双语网页翻译开发版

本地开发分支：`bilingual-translation`，基于官方 `chrome-mv3` 分支。

## 安装到 Chrome / Edge

1. 执行 `npm ci`，再执行 `npm run build:local-sourcemaps`。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择 `build/TWP_AI_0.1.0_Chromium_MV3` 文件夹。直接加载 `src` 文件夹开发时，先运行 `npm run build:ai` 生成后台 SDK 包。
5. 打开普通英文网页，点击扩展图标，选择中文作为目标语言，再点击“翻译”。
6. 弹窗中的“网页显示方式”默认为“双语对照（原文 + 译文）”。选择“仅显示译文”可以回到 TWP 原来的替换模式；点击“显示原文”可清除译文。

修改代码后，如果加载的是 `build` 中的目录，先重新执行 `npm run build:local-sourcemaps`。然后在扩展管理页面点击“重新加载”，并刷新需要翻译的网页。

如果点击翻译后没有译文：先确认目标语言为中文，暂时停用同页的其他翻译扩展并刷新网页；再切换 Google / Bing 重试。双语模式会显示等待或失败提示。普通服务请求 30 秒超时；AI 每次网络请求最多 25 秒，包含排队和重试的总任务最多 55 秒。

## 悬浮工具与 AI 服务

网页右侧显示蓝色双语图标：点击翻译，再次点击恢复原文；翻译过程中点击可取消。悬停后，上方的四格图标打开翻译侧边栏，下方的滑杆图标打开“控制面板”。拖动中间图标可调整高度及左右贴边位置。“控制面板”可调整目标语言、服务、AI 领域和划词开关，也可以隐藏当前网站的按钮。

1. 点击控制面板中的“模型与术语设置”、侧边栏的设置图标，或扩展弹窗中的“AI 服务 / 术语 / 悬浮按钮设置”。
2. 填入服务名称、API Base URL、模型 ID 和自己的 API Key。地址也接受完整的 `/chat/completions` 后缀。本机免密服务可不填密钥。
3. 保存服务，点击“测试连接”；此操作向所填 API 发送一段固定示例文本，可能产生少量费用。
4. 在翻译偏好中选择当前服务、机器学习 / 软件开发等领域、缩写策略，以及每行 `原文 = 译文` 的术语库，保存偏好。
5. 将默认网页服务切换为 AI，或在悬浮面板切换。AI 网页翻译本版采用双语对照；传统服务仍支持仅译文。
6. 在网页选中文字，点击划词图标或控制面板里的“翻译选中文字”可单独翻译，使用控制面板当前的服务与目标语言。AI 设置页也支持粘贴文本、试译、取消和复制译文。

### 控制面板快捷功能

- 文档翻译 / 文本翻译：打开扩展内的独立工作台标签页。宽屏文本工作台将原文与译文并排展示；上方四格图标仍打开原生侧边栏。
- 鼠标悬停：默认关闭。鼠标移到正文段落后，单独按下再松开 Ctrl / Shift / Alt，可翻译 / 还原该段；支持仅翻译、仅还原。也可选择长按鼠标左键约 0.7 秒，或直接悬停约 0.7 秒。直接悬停固定为仅翻译，避免反复进出段落导致意外还原。
- 划词翻译：可启用 / 关闭，支持显示图标、显示小圆点、直接翻译，或选中文字后按 Ctrl / Alt / Shift。直接翻译会在每次完成划词后请求所选服务。
- 英文单词划词时附加词典卡片：英美音标、对应口音的浏览器朗读、词性、释义、例句、近义词及可用词源。释义与例句沿用当前翻译服务和目标语言；先显示英文词条并翻译释义，例句点击「翻译例句」后翻译。词条在浏览器会话内存缓存最多 100 项、24 小时，支持跨 MV3 后台休眠复用；释义译文在当前网页缓存最多 100 组，设置变化后清除。普通句子保持简洁译文。词典使用 Free Dictionary API，显示原始来源和许可，支持常见复数回查词典词形；缺失音标或口音语音会明确提示，不猜测。关闭、换词、取消和切换服务时丢弃迟到结果，词典查询失败不影响主译文。
- 圈选翻译：明确展示尚未支持；没有截图或 OCR 的无效开关。

桌面版的新划词 / 悬停功能接管旧版自动触发入口，避免重复弹窗。Ctrl+C 等组合键、输入框、编辑区、代码和导航不会自动触发。整页翻译开始时清除单段译文并暂停悬停翻译；还原段落、修改原文、切换服务或术语配置后，迟到的结果不能重新写入页面。移动端保留旧版交互。

使用 `ai` 和 `@ai-sdk/openai-compatible`，SDK 随扩展打包，直接请求用户配置的接口；无需部署 LiteLLM、Vercel 服务或其他网关。文本按段落 ID 校验并对应，代码片段、公式和 URL 使用占位符保护。缓存只保存在后台内存中，切换服务、领域或术语配置后失效。页面恢复、导航或关闭时取消相关 AI 请求。提供服务不兼容、密钥失效、限流、返回格式错误等提示，不自动改用其他厂商。

API Key 保存在扩展 origin 的独立 IndexedDB 中，内容脚本不能通过配置接口取出密钥，普通设置导出也不包含它。该存储不提供本机磁盘加密；卸载扩展会删除配置。改变已有服务的地址时需重新填写或显式清除密钥。

未使用个人模型密钥做外部服务实测，兼容性测试使用本机模拟 OpenAI Chat Completions 接口。

## 翻译侧边栏

Chrome / Edge 116+ 使用浏览器原生侧边栏，不往网页中插入固定宽度的遮挡层；没有 `sidePanel.open` API 的浏览器在新标签页显示同一工作台。原生入口按 [Chrome Side Panel API](https://developer.chrome.com/docs/extensions/reference/api/sidePanel) 在用户点击的消息处理器内直接调用，避免异步等待丢失用户手势。新增 `sidePanel` 权限后，需要重新加载扩展并刷新网页。

- 文本：自动检测原语言，支持微软、谷歌、Yandex 和现有自定义 AI；支持 Ctrl/Cmd + Enter、取消和复制。每次最多 16000 字符。
- 文档：导入 UTF-8 TXT，分批翻译后下载文本，保留原文换行与空白行。
- 视频：目前支持 SRT / VTT 字幕文件，保留时间轴、编号、VTT 元数据；可导出双语或仅译文字幕。
- 图片：展示明确的“规划中”状态，并提供前往文本翻译的入口；没有图片上传功能。
- 指南：说明模型配置、网页控制和文件导入流程。

文件限制为 200 KB / 100000 字符。选择文件只在本地读取，点击翻译才发送文字到所选服务。取消或出错不会提供不完整文件下载。侧边栏的服务与目标语言独立保存，不改变整页翻译服务；文档模型独立保存；文本对比为每个模型发送独立请求，不切换全局当前模型。关闭面板不保存输入内容。PDF / DOCX / EPUB 排版、网页实时视频字幕、语音识别和图片 OCR 尚未接入。

## 本版功能

- 在原段落下方插入译文，保留原始文本、链接和事件处理器。
- 整页与悬停翻译按网页 CSS 空白规则处理输入，避免 HTML 源码的换行、缩进变成译文中的断行；保留显式换行与预格式文本。
- 正文与列表中的行内代码、数值和键名作为完整句子的一部分翻译，原样保留代码内容；行内链接（含 `inline-block`）不单独拆段。代码块及独立代码仍跳过，避免在一行原文中穿插多段译文。
- 译文中的上标、下标、加粗、斜体、下划线、删除线、高亮、注音和换行等常见行内标记按白名单渲染，支持嵌套并保留原公式；丢弃服务返回的标签属性，未知标签作为文字显示。
- 对 inlineDisqussions 的段落评论气泡同步原段落/图片的位置，避免双语译文改变正文高度后气泡落入正文；评论入口不参与翻译，保留原点击行为，支持调整窗口、动态内容和还原原文。
- 复用 TWP 的翻译服务、自定义词典和缓存。
- 先翻译视口附近的内容，滚动时继续翻译。
- 根据“翻译动态创建的内容”设置处理新增、修改和删除的段落。
- 跳过代码块、编辑区、导航、按钮和网站明确标记为不翻译的内容。
- 标签页控件使用原文与译文同行的紧凑排版，避免固定高度导航裁切文字；若仍放不下，保留原控件。正文保持上下双语对照。
- 支持弹窗两种布局和设置页切换显示方式，设置保存在本地。
- 译文按纯文本显示；恢复原文或切换模式后，旧请求不会重新插入双语译文。

本版完成普通网页的双语翻译和侧边栏文本 / TXT / 字幕文件翻译；不包含图片识别、实时视频字幕和完整 PDF 排版功能。
TWP 自带 PDF 页面继续使用原来的替换模式。尚未处理 Shadow DOM 中的内容。

完整离线词库已接入划词：ECDICT 完整压缩版包含 3,402,564 条记录，随包分发，按需读取本地索引。简体中文目标下直接使用已有中文释义，本地未收录才自动查在线词典，也可点击「补充在线释义与例句」。详细来源、限制和重建说明见 [离线词典说明](offline-dictionary.md)。

## 验证

```powershell
npm test
npm run test:background
npm run build:local-sourcemaps
npm run test:extension
npm run test:ai
npm run test:ai-extension
npm run test:sidebar
```

Windows 默认使用已安装的 Edge 做无界面测试。可用环境变量 `TWP_BROWSER_CHANNEL` 选择 `chrome` 或 `chromium`；使用 Chromium 时先运行 `npx playwright install chromium`。

自动化测试使用固定的翻译响应，验证显示、恢复、取消、动态更新和真实扩展消息传递；不代表对 Google、Bing 等外部服务的联网可用性验证。实际翻译仍需要浏览器可以访问所选服务。

2026-10-03 另用隔离的 Edge 配置进行了联网验证：Google 和 Bing 均返回中文；Kaggle Titanic 数据页使用 Bing 实际显示了标题和正文的双语译文。该结果不保证其他浏览器配置或后续时间的服务可用性。

## 主要代码

- `src/contentScript/bilingualTranslator.js`：段落收集、视口翻译、译文插入、动态更新和清理。
- `src/contentScript/pageTranslator.js`：复用 TWP 服务并衔接两种显示模式。
- `src/lib/translationMode.js`：弹窗和设置页共用的模式选择。
- `tests/bilingual.spec.js`：真实浏览器中的内容脚本行为测试。
- `tests/extension-smoke.cjs`：完整 MV3 扩展加载和消息传递验证。
- `tests/background-audio.cjs`：朗读后台的延迟初始化、配置同步、并发创建、失败重试与消息接收端关闭场景。
- `extension/ai-service.js`：SDK、私有服务配置、请求队列、取消、缓存、术语提示与响应校验。
- `src/contentScript/floatingTranslator.js`：悬浮按钮、快捷设置、选中文字 AI 翻译。
- `src/contentScript/interactiveTranslator.js`：桌面段落悬停、划词触发、服务路由、取消和独立结果浮窗。
- `src/options/ai.html`：AI 服务配置与文本试译工作台。
- `src/options/sidepanel.html` / `sidepanel.js` / `sidepanel.css`：文本、文件和字幕翻译侧边栏。
- `src/background/sidePanel.js`：原生侧边栏入口与旧浏览器工作台回退。
- `src/lib/documentTranslation.js`：TXT / SRT / VTT 解析与导出，保留非翻译结构。
- `tests/documents.cjs` / `tests/sidepanel-background.cjs` / `tests/sidepanel-flow.cjs`：格式保持、用户手势、原生打开与侧边栏翻译、取消和下载验证。
- `tests/control-panel-flow.cjs`：控制面板配置、工作台入口、段落翻译 / 还原、快捷键防误触和划词模式的真实扩展测试。
- `tests/ai-service.cjs` / `tests/ai-extension.cjs`：模型输出校验、密钥隔离，以及真实 MV3 扩展中的本机 API 集成测试。

保留上游许可证和署名；本地改动尚未推送到 GitHub。


## 多模型对比与专家库

文本支持 Google、Bing、Yandex 和多个已配置 AI 模型对比；按段双语展示，复制、导出和失败重试互相独立。默认数据已纳入源码：41 个参考专家类别使用重写提示词，另有 3 个基础专家；保留 30 个非电子游戏参考术语库，其中访问控制扩展为计算机科学，另新增 LLM / AI 库；其余参考库的语言版本和词条数量不变。原始专家备份和移除的游戏库不进入发布包；来源及许可说明见 [预设说明](public-presets.md)。
