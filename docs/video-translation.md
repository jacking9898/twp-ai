# 网页视频字幕翻译

视频页面自动在播放器底部显示页渡图标；B 站在右侧原生控制行内预留独立位置，悬停或点击图标可打开字幕翻译开关和字幕设置。直接开启使用当前服务与已保存的页面偏好，不刷新页面、不重置播放进度；首次点击才读取字幕列表和发送翻译请求。字幕设置中可选择播放器、原字幕语言、翻译服务和目标语言；AI 可选择模型，并使用该视频页面的专家、风格、内置术语库和已保存的专属术语。收起设置只隐藏面板，翻译继续；关闭滑动开关才停止翻译并恢复原字幕。悬浮控制面板中的「视频翻译」入口也保留。

播放器容器全屏时入口跟随播放器；视频元素本身进入原生全屏时，浏览器仅显示视频与原生字幕，退出全屏后可操作入口。页面偏好复用已有作用域设置。

## 已接入的字幕来源

通用播放器的入口放在视频下方，不覆盖浏览器原生控制条；B 站入口放在底部控制区。

- 当前主页面 HTML 视频的 subtitles / captions 文字轨道。轨道原本关闭时，在启动翻译后临时以 hidden 模式读取字幕，停止时恢复此前状态。
- B 站视频 BV / av 及具体 ep 剧集页面。后台读取视频元数据、当前分 P / 剧集的 aid 和 cid，再读取播放器字幕列表。字幕接口要求登录时会提示先登录 B 站；仅使用浏览器现有登录状态，不读取、保存或发送登录 Cookie 给翻译服务。
- 用户导入当前视频的 SRT / VTT。最多 200 KB；使用文件中的时间轴，适合没有可访问文字轨道的播放器。

字幕统一为开始时间、结束时间、文字；支持重叠字幕并去除完全重复条目。单条最多 3000 字符，轨道最多 20000 条 / 100 万字符。当前不读取跨域 iframe 内部播放器，不自动识别画面内字幕或音频；画面内文字仍可暂停后圈选 OCR。

## 翻译与播放

默认只翻译当前位置到后续约 60 秒的未完成字幕，每批最多 8 条 / 3000 字符。相邻字幕合并为一个带独立条目 ID 的请求，保留批内语境和时间轴。AI 复用已有按文字段缓存；重开或重新开始会通过共享缓存查找，避免面板内存绕过术语更新或缓存删除。

普通播放和播放器容器全屏使用页渡双语覆盖层。视频元素本身进入原生全屏时改用播放器的 TextTrack / VTTCue 显示。根据 currentTime 同步，暂停、倍速、拖动进度无需重新计算字幕时间；跳转取消旧批次并优先处理新位置。播放器加载新资源、视频被移除、页面 URL / 分 P 改变或用户停止时终止旧调度并恢复原字幕。失败后停止自动请求，保留已完成结果，等待手动重试。

默认仅显示译文，保留网站原字幕；视频画面已有英文时只补一行中文。译文未就绪时不重复添加英文；用户也可选择原文 + 译文，此时隐藏网站可控的原字幕。覆盖层居中，各行使用随文字宽度收缩的半透明深色背景。点击「翻译全部字幕」会逐批处理整条轨道，可能产生更多 AI 用量。可以导出已完成的双语 SRT；不完整的文件名带 partial。

B 站字幕避让兼容当前 `bili-subtitle-x` 渲染器及旧播放器节点：测量实际文字范围，移动内部字幕定位块，不把覆盖整个视频的面板当作文字框。控制栏显隐、原字幕换行或节点替换时重新计算间距；停止时恢复网站样式。双语模式隐藏对应网站字幕层，避免重复叠加。回归结构已按 B 站公开播放器 `npd.990.adbc0bc3.js` 的定位块和文字节点核对。

首次默认优先选择与目标语言不同的源轨道；手动选择和重新检测保持用户的轨道选择。同语源字幕直接显示，状态明确说明未调用翻译服务，双语模式也不重复同一文本。每条 B 站轨道使用独立 ID（缺失时使用字幕路径），避免同语言轨道混淆；自动选择不覆盖用户明确选择的轨道。显示模式仅改变排版，不停止调度、不重新请求。面板显示轨道条数、时间范围，以及当前条目的开始/结束时间、源文和译文；当前时间没有字幕时说明下一条时间或轨道已经结束。画面中烧录的文字仍属于视频像素，无法通过轨道开关隐藏。

已读取的 B 站时间轴在标签页会话中保留 30 分钟，支持刷新网页或扩展后台休眠后恢复；按标签页和视频 aid / cid 隔离，每个标签页仅保存最近视频的最多 8 条轨道，并限制总字符量。浏览器支持时使用 storage.session，否则仅保存在后台内存；关闭标签页时清理。接口暂时返回空列表或部分轨道时保留此前已读时间轴，不把其他视频字幕混入当前视频。翻译中可直接切换轨道，切换会取消旧请求并载入所选轨道，无需先停止翻译。

每次点击检测或首次启动时，即使后台已返回部分轨道，也会从当前视频网页发起 B 站播放器接口请求，使用浏览器已有的同站点登录凭据。除通用 v2 列表外，还合并该标签页播放器实际请求的 v2 / wbi/v2 列表；仅复用已观察到、且 aid / cid（或 bvid / cid）匹配当前视频分 P 的 HTTPS 接口地址，不生成签名。后台签发的短期列表令牌限定标签页、URL 和已解析的视频；收到网页轨道后仍验证字幕 CDN 域名及路径，并按轨道 ID 合并两次结果。该路径不能获得字幕时保留后台提示及此前读取的时间轴，不绕过登录要求。

## 数据与验证

只有点击开始后才把字幕文字发送给所选翻译服务；不上传视频或音频。B 站字幕获取仅访问其固定元数据接口以及字幕列表返回、经过域名和路径验证的 HTTPS 字幕 CDN 地址；字幕选择令牌限定于原标签页和 URL，10 分钟后失效。视频字幕译文可在已有缓存管理中按页面标题查找和删除。

`npm run test:video` 包含字幕规范化 / 时间轴 / 导出单元测试、后台信任边界和 B 站分 P / 登录 / 剧集 / 令牌测试，以及真实 Chromium 扩展集成测试。集成测试使用本机生成的可跳转媒介时间轴，验证提前翻译、倍速与跳转、全屏模式、缓存、停止 / 恢复、取消、失败重试、字幕文件、免费与 AI 服务、窄屏、B 站适配及 SPA 切换清理。字幕和 AI 接口使用确定性本地响应，不调用用户模型计费接口。
