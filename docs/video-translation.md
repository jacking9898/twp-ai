# 网页视频字幕翻译

视频页面自动在播放器底部显示页渡图标；B 站在右侧原生控制行内预留独立位置，悬停或点击图标可打开字幕翻译开关和字幕设置。直接开启使用当前服务与已保存的页面偏好，不刷新页面、不重置播放进度；B 站与 YouTube 默认在播放器就绪后自动检测，有可读取字幕就自动开始，优先英语轨道，默认译为简体中文；只有中文时直接显示，不调用翻译服务。没有轨道或正文尚未加载时保持关闭，不弹出面板或播放器错误提示；设置面板保留具体原因。初始检测最多三次，YouTube 播放器稍后收到新字幕正文时最多再唤醒三次，正文仍需通过当前视频与轨道校验。手动关闭只记住该视频，刷新后仍关闭；其他视频继续按有无可读字幕决定。服务、模型、目标语言和显示方式按网站复用。无痕窗口与无法可靠识别视频的通用播放器只手动开启。画面中文字不一定对应平台提供的文字轨道。字幕设置中可选择播放器、原字幕语言、翻译服务和目标语言；AI 可选择模型，并使用该视频页面的专家、风格、内置术语库和已保存的专属术语。收起设置只隐藏面板，翻译继续；关闭滑动开关才停止翻译并恢复原字幕。悬浮控制面板中的「视频翻译」入口也保留。

播放器容器全屏时入口跟随播放器；视频元素本身进入原生全屏时，浏览器仅显示视频与原生字幕，退出全屏后可操作入口。页面偏好复用已有作用域设置。

## 已接入的字幕来源

通用播放器的入口放在视频下方，不覆盖浏览器原生控制条；B 站和 YouTube 入口放在底部控制区。平台播放器刷新时等待控制栏和有效布局就绪后显示图标，不使用视频下方的通用位置；控制栏重新创建后重新绑定图标位置。

播放器菜单的「字幕设置」先展开快捷选项：字幕显示、目标语言、翻译服务。「更多设置」才打开完整面板，选择轨道、模型、专家、术语库与风格，或导入、导出字幕。快捷选项与完整面板双向同步；翻译中可以立即切换字幕显示、服务、模型和目标语言。服务、模型或语言改变时取消旧请求、清除旧译文，从当前播放位置重新翻译；迟到的旧响应不回写，不刷新页面或重置播放进度。专家、术语库与风格始终可见，普通翻译服务下可预先保存配置，切换 AI 服务后才应用；面板提供切换 AI 与管理模型、术语的入口。

- 当前主页面 HTML 视频的 subtitles / captions 文字轨道。轨道原本关闭时，在启动翻译后临时以 hidden 模式读取字幕，停止时恢复此前状态。
- B 站视频 BV / av 及具体 ep 剧集页面。后台读取视频元数据、当前分 P / 剧集的 aid 和 cid，再读取播放器字幕列表。字幕接口要求登录时会提示先登录 B 站；仅使用浏览器现有登录状态，不读取、保存或发送登录 Cookie 给翻译服务。
- YouTube 主页面播放器：读取当前播放器的手动字幕和自动字幕，并标记自动字幕。优先使用播放器当前已加载的字幕请求地址，支持 JSON3 及 XML 时间轴；自动字幕的分词追加事件合并为完整条目。没有字幕时可开启网站 CC 后重新检测，或导入字幕文件；不生成访问令牌、不绕过登录限制、不进行语音识别。普通 watch 页面为主要验证范围，独立 shorts / embed 地址可解析；跨站嵌入的 iframe 不在当前支持范围。直播只能读取平台当时已生成的部分字幕。
- 用户导入当前视频的 SRT / VTT。最多 200 KB；使用文件中的时间轴，适合没有可访问文字轨道的播放器。

字幕统一为开始时间、结束时间、文字；支持重叠字幕并去除完全重复条目。单条最多 3000 字符，轨道最多 20000 条 / 100 万字符。当前不读取跨域 iframe 内部播放器，不自动识别画面内字幕或音频；画面内文字仍可暂停后圈选 OCR。

## 翻译与播放

默认只翻译当前位置到后续约 60 秒的未完成字幕，每批最多 8 条 / 3000 字符。相邻字幕合并为一个带独立条目 ID 的请求，保留批内语境和时间轴。AI 复用已有按文字段缓存；重开或重新开始会通过共享缓存查找，避免面板内存绕过术语更新或缓存删除。

普通播放和播放器容器全屏使用页渡双语覆盖层。视频元素本身进入原生全屏时改用播放器的 TextTrack / VTTCue 显示。根据 currentTime 同步，暂停、倍速、拖动进度无需重新计算字幕时间；跳转取消旧批次并优先处理新位置。播放器加载新资源、视频被移除、页面 URL / 分 P 改变或用户停止时终止旧调度并恢复原字幕。失败后停止自动请求，保留已完成结果，等待手动重试。

默认仅显示译文，保留网站原字幕；视频画面已有英文时只补一行中文。译文未就绪时不重复添加英文；用户也可选择原文 + 译文，此时隐藏网站可控的原字幕。覆盖层居中，各行使用随文字宽度收缩的半透明深色背景。点击「翻译全部字幕」会逐批处理整条轨道，可能产生更多 AI 用量。可以导出已完成的双语 SRT；不完整的文件名带 partial。

B 站字幕避让兼容当前 `bili-subtitle-x` 渲染器及旧播放器节点：测量实际文字范围，移动内部字幕定位块，不把覆盖整个视频的面板当作文字框。控制栏显隐、原字幕换行或节点替换时重新计算间距；停止时恢复网站样式。双语模式隐藏对应网站字幕层，避免重复叠加。回归结构已按 B 站公开播放器 `npd.990.adbc0bc3.js` 的定位块和文字节点核对。

YouTube 图标按整个播放器容器定位，兼容宽屏模式下延伸至视频黑边的原生控制栏；图标放在原播放器右侧控制行，字幕避开底部控制栏。仅译文模式保留网站 CC，并为译文留出间距；原文 + 译文模式隐藏网站原字幕，防止重复显示。广告期间不显示正片译文、不继续请求翻译；站内切换视频立即停止旧调度，新的检测按视频 ID 和标签页绑定，不能串用其他视频或标签页的轨道。

YouTube 在页面加载时观察播放器自身的 fetch / XHR 字幕响应，优先复用已收到的正文，避免签名地址重复请求返回空内容。只保留当前视频、原语言轨道的正文，最多 8 条 / 400 万字符 / 30 分钟，限当前页面内存；刷新、离开或切换视频后清理。不读取请求头、Cookie 或其他接口正文；没有捕获结果时才按原始地址尝试读取，不改写格式参数。已找到轨道但正文为空时明确提示读取失败，不把它报告成未开启字幕。

视频翻译默认目标语言为简体中文，不继承网页翻译的目标语言。首次有英语轨道时优先选择英语（同语言优先平台手动轨道），无英语则选择其他可用轨道；手动选择和重新检测保持用户的轨道选择。源、目标同语时直接显示，简体与繁体中文也不调用翻译服务，状态明确说明未调用翻译服务，双语模式也不重复同一文本。每条 B 站轨道使用独立 ID（缺失时使用字幕路径），避免同语言轨道混淆；自动选择不覆盖用户明确选择的轨道。显示模式仅改变排版，不停止调度、不重新请求。面板显示轨道条数、时间范围，以及当前条目的开始/结束时间、源文和译文；当前时间没有字幕时说明下一条时间或轨道已经结束。画面中烧录的文字仍属于视频像素，无法通过轨道开关隐藏。

已读取的 B 站时间轴在标签页会话中保留 30 分钟，支持刷新网页或扩展后台休眠后恢复；按标签页和视频 aid / cid 隔离，每个标签页仅保存最近视频的最多 8 条轨道，并限制总字符量。浏览器支持时使用 storage.session，否则仅保存在后台内存；关闭标签页时清理。接口暂时返回空列表或部分轨道时保留此前已读时间轴，不把其他视频字幕混入当前视频。翻译中可直接切换轨道，切换会取消旧请求并载入所选轨道，无需先停止翻译。

每次点击检测或首次启动时，即使后台已返回部分轨道，也会从当前视频网页发起 B 站播放器接口请求，使用浏览器已有的同站点登录凭据。除通用 v2 列表外，还合并该标签页播放器实际请求的 v2 / wbi/v2 列表；仅复用已观察到、且 aid / cid（或 bvid / cid）匹配当前视频分 P 的 HTTPS 接口地址，不生成签名。后台签发的短期列表令牌限定标签页、URL 和已解析的视频；收到网页轨道后仍验证字幕 CDN 域名及路径，并按轨道 ID 合并两次结果。该路径不能获得字幕时保留后台提示及此前读取的时间轴，不绕过登录要求。

## 数据与验证

只有点击开始后才把字幕文字发送给所选翻译服务；不上传视频或音频。B 站字幕获取仅访问其固定元数据接口以及字幕列表返回、经过域名和路径验证的 HTTPS 字幕 CDN 地址；字幕选择令牌限定于原标签页和 URL，10 分钟后失效。视频字幕译文可在已有缓存管理中按页面标题查找和删除。

YouTube 使用 `scripting` 权限，在当前标签页的网页执行环境中只读播放器元数据，并按需请求该视频的 `/api/timedtext`。调用仅传入视频 ID、操作和已验证的字幕地址，不传入模型、专家设置、API Key 或扩展存储。返回结果视为不可信数据，再校验域名、路径、视频 ID、时间轴和大小。老版本浏览器不支持 MAIN world 时会提示更新或导入字幕。此设计遵循 [Chrome scripting](https://developer.chrome.com/docs/extensions/reference/api/scripting) 与 [MDN ExecutionWorld](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/scripting/ExecutionWorld) 的执行环境约束。

`npm run test:video` 包含字幕规范化 / 时间轴 / 导出单元测试、后台信任边界和 B 站分 P / 登录 / 剧集 / 令牌测试，以及真实 Chromium 扩展集成测试。集成测试使用本机生成的可跳转媒介时间轴，验证提前翻译、倍速与跳转、全屏模式、缓存、停止 / 恢复、取消、失败重试、字幕文件、免费与 AI 服务、窄屏、B 站适配及 SPA 切换清理。YouTube 用真实 MAIN world 脚本桥验证手动 / 自动 / XML 字幕、控制栏显隐避让、广告隐藏及站内切换清理。字幕和 AI 接口使用确定性本地响应，不调用用户模型计费接口；这不替代登录环境下的线上视频验证。
